# Tiodozap
Tiodozap é o tio do grupo da família que tem opinião sobre absolutamente tudo.  Converse com ele, tente argumentar e veja até onde vai essa discussão. Prepare-se para ouvir “eu vi num vídeo”, “manda a fonte”, “e o PT?” e outras pérolas.  Você consegue fazer o TioMinion admitir que está errado?
